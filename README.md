# DataGrid-Analytics
Production-grade, schema-agnostic retail data lakehouse combining historical batch processing and real-time event streaming. Implements a Medallion Architecture (Bronze → Silver → Gold) with SCD Type 2 tracking, DuckDB OLAP analytical queries, FastAPI REST service, and an interactive React analytics dashboard powered by AI natural-language querying
